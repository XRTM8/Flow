# 🌊 FLOW by Otium
> **جسر محلي فوري فائق الخفة لنقل الملفات والحافظة بين الحاسوب والهاتف بلغة Rust بالكامل 100%.**
> *100% Pure Rust Native Cross-Platform P2P Sync (Zero JavaScript, Zero WebView, Zero Electron/Tauri bloat).*

---

## 🏛️ فلسفة التصميم (Design Philosophy)

صُمم **FLOW** ليكون بديلاً حقيقياً وأصلياً لأدوات المشاركة المعقدة:
1. **Rust أصلي بالكامل (100% Pure Rust):** لا وجود لـ Node.js أو React أو Vite أو Webview. واجهة التطبيق مرسومة ومبنية بمكتبة **Slint** الأصلية ومترجمة إلى كود آلة سريع ومباشر.
2. **استهلاك موارد شبه معدوم:** يستهلك التطبيق قرابة **15-20 ميجابايت رام** فقط، ويعمل بخفة تامة في الخلفية دون أي تأثير على بطارية الهاتف أو موارد المعالج.
3. **تصميم إنساني نظيف وراقٍ:** واجهة بسيطة واحترافية خالية تماماً من فوضى قوالب الذكاء الاصطناعي وبطاقات الحشو غير الضرورية.

## 📱 مراعاة بيئة كل جهاز (Desktop vs Mobile Separated)

* **واجهة الحاسوب (Desktop Window):**
  * نافذة عائمة مدمجة (360×540px) مخصصة للفأرة وسحب وإفلات الملفات المباشر (Drag & Drop Zone).
  * بطاقة الحافظة اللحظية (Live Clipboard) تظهر النصوص المنسوخة تلقائياً مع تنظيف فوري لوسوم التتبع.
  * زر وصول سريع لسجل التحويلات السابق (📜 Activity History Drawer).
  * مؤشر اتصال ذكي ومستقر مع أجهزتك المتصلة بنفس شبكة الـ Wi-Fi أو نقطة اتصال الهاتف (Mobile Hotspot).

* **واجهة الهاتف (Mobile View):**
  * **مراعاة مكان البردة (Status Bar / Notch Safe Area Inset):** مسافة أمان علوية تلقائية (`safe_area_top: 48px`) تحمي الواجهة من التداخل مع كاميرا الهاتف أو شريط إشعارات أندرويد (البردة).
  * **حماية شريط الإيماءات السفلي (`safe_area_bottom: 34px`):** لضمان عدم تداخل الأزرار مع شريط الرجوع أو زر الشاشة الرئيسية.
  * **أزرار مصممة لمنطقة الإبهام (One-Handed Thumb Zone):** أزرار مشاركة كبيرة في متناول يدك بالأسفل لاختيار ملف أو عدة صور دفعة واحدة.
  * **سجل تحويلات منبثق بلمسة واحدة:** استعراض تاريخ الملفات والنصوص المستلمة مع خيار تفريغ السجل.

## 🛡️ الأمان والصلابة الهندسية (Security & Robustness)

1. **التحقق التشفيري المسبق من سلامة البيانات (Pre-Calculated SHA-256 Checksum):**
   * احتساب تلقائي مسبق للبصمة التشفيرية وإرسالها بالترويسة للتحقق التام من سلامة الملفات ورفض أي حزم معطوبة.
2. **تشفير عسكري من طرف لطرف مع Nonce عشوائي (ChaCha20-Poly1305 E2EE with Random Nonce):**
   * توليد قيمة Nonce عشوائية فريدة 96-bit لكل رسالة مشفرة تمنع تماماً هجمات كسر المفتاح أو إعادة استخدام الـ Nonce.
3. **الحماية ضد هجمات التعليق الشبكي (Slowloris Network Timeout Protection):**
   * مهلة أمان زمنية (15 ثانية) على كافة عمليات قراءة المقابس لإنهاء أي اتصال معلق عمداً أو ناتج عن تشويش الشبكة.
4. **حماية القرص وسقف الملفات (Disk Exhaustion Protection):**
   * حظر تلقائي لأي ملف يتجاوز حجمه 50 جيجابايت لمنع هجمات ملء القرص الصلب.
5. **تنظيم الاتصالات المتزامنة (Concurrency Limiter):**
   * محدد اتصالات عبر Semaphore (16 اتصال متزامن كحد أقصى) لحماية السيرفر من هجمات إغراق المقابس (Socket Exhaustion).
6. **الحفظ الذري المعزول (Isolated `.flowpart` with UUID):**
   * استخدام معرفات UUID للملفات المؤقتة لمنع أي تداخل أو تلف في البيانات عند استلام ملفات متعددة متزامنة بنفس الاسم.
7. **منع اختراق المسارات وحظر المحارف المحظورة (OS-Safe File Sanitizer):**
   * استبعاد صارم لكافة محارف أنظمة التشغيل المحظورة (`:`, `*`, `?`, `<`, `>`, `|`, `\`, `/`) مع دعم كامل للأسماء العربية واليونيكود والمسافات والأقواس.
8. **حماية أطوال المسارات (Windows MAX_PATH Protection):**
   * اقتصاص ذكي لأسماء الملفات المفرطة في الطول (>100 حرف) مع الحفاظ على الامتداد لمنع أخطاء نظام الملفات.
9. **استقرار الأجهزة المتعددة (Peer Connection Stabilization):**
   * تثبيت الجهاز المتصل وترتيب الأجهزة هجائياً لمنع التخبط العشوائي في الشبكات التي تحتوي على عدة أجهزة نشطة.
10. **التعافي الذكي من أخطاء النقل (Graceful Error Recovery):**
    * تنبيه فوري بالخطأ في الواجهة وإعادة تعيين المؤشرات تلقائياً دون أي تجميد للبرنامج.

## ⚡ الميزات التقنية (Core Features)

1. **دعم تشغيل عدة أجهزة على نفس الحاسوب للاختبار (SO_REUSEADDR & Dynamic Ports):**
   * يمكنك تشغيل واجهة الحاسوب وواجهة الهاتف معاً على نفس الجهاز في نافذتين منفصلتين؛ حيث يتم اختيار المنافذ ديناميكياً ويكتشف كل منهما الآخر فوراً.
2. **نقل حزم ملفات متعددة (Multi-File Batch Streaming):**
   * إمكانية تحديد عدة ملفات أو صور دفعة واحدة وإرسالها بتدفق متتابع مع عداد للتقدم `[1/5]`.
3. **عدّاد السرعة الحية والوقت المتبقي (Live Speed & ETA):**
   * احتساب السرعة بالـ MB/s وعرض الثواني المتبقية لحظياً بدقة متناهية.
4. **اكتشاف تلقائي فوري يدعم نقاط الاتصال (Hotspot & Subnet Discovery):**
   * بث ذكي يستهدف راوترات Wi-Fi العادية ونقاط اتصال أندرويد وآيفون.
5. **سرعة نقل فائقة (Throughput ~500 MB/s):**
   * نقل الملفات مباشرة من القرص إلى كرت الشبكة عبر مخازن مؤقتة بحجم 64KB دون استهلاك الذاكرة.
6. **تطهير الروابط الذكي (Smart Link Cleaner):**
   * إزالة وسوم التتبع الإعلانية والمراقبة (`utm_*`, `si`, `fbclid`, `igshid`) من الروابط المنفردة أو المضمنة داخل النصوص مع الحفاظ على فروع GitHub ووسوم الهاشتاغ.

## 🤖 بناء حزمة أندرويد (Android APK Build)

تم تضمين ملف التعريف `android/AndroidManifest.xml` وسكربتات البناء الآلية لبناء تطبيق أندرويد أصلي خالص:
```powershell
# على ويندوز عبر PowerShell:
.\scripts\build_android.ps1
```
```bash
# على لينكس / ماك:
./scripts/build_android.sh
```

## 🚀 التشغيل والتجربة على نفس الجهاز (Run & Test Locally)

### للتجربة العملية بين الحاسوب والهاتف على نفس جهازك:
1. **في موجه الأوامر الأول (واجهة الحاسوب):**
   ```bash
   cargo run
   ```
2. **في موجه الأوامر الثاني (محاكاة الهاتف):**
   ```bash
   cargo run -- --mobile
   ```
