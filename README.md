# Flow by Otium — 2.4.2

نقل الملفات والنصوص بين أجهزتك عبر الشبكة المحلية. منطق التطبيق وتكامل النظام بلغة Rust، والواجهة وصفية بـSlint وتُترجم إلى تطبيق أصلي. لا JavaScript أو WebView أو Electron.

## الاستخدام

1. افتح Flow على الجهازين واتصل بالشبكة المحلية نفسها.
2. اختر الجهاز المستلم صراحةً من الأجهزة القريبة. اكتشاف جهاز لا يعني الاتصال به.
3. افتح الاقتران على الجهازين. انسخ رمز كل جهاز إلى الحقل المقابل على الجهاز الآخر عبر قناة موثوقة. الرمز سري ومكوّن من 64 خانة؛ لا يُرسل عبر اكتشاف الشبكة.
4. بعد التحقق المتبادل، تظهر حالة «جاهز للإرسال» ويصبح اختيار الملفات وإرسال النص متاحين.
5. اسحب ملفات إلى نافذة الحاسوب أو اخترها. على الهاتف استخدم متصفح الملفات الأصلي داخل Flow، وامنحه الوصول للملفات عند الحاجة، ثم اضغط تحديث بعد العودة من إعدادات النظام.

لا يتغير المستلم تلقائيًا عند اختفائه. يحتفظ التطبيق بالاختيار ويعرض أن الجهاز غير متاح. يمكن إلغاء اقتران الأجهزة حتى أثناء عدم اتصالها من الإعدادات.

## الواجهة

- مظهر AMOLED افتراضي بخلفية أسود خالص، وألواح زجاجية داكنة شفافة بحواف خفيفة ونصوص فضية واضحة. تُحفظ تفضيلات المظهر السابقة، ويتوفر المظهر الفاتح من الإعدادات.
- شريط مختصر للمستلم، وصفحة مستقلة للأجهزة، وإجراءات واضحة عند عدم الاتصال، وسجل وإعدادات مستقلان.
- العربية وRTL والإنجليزية، مع أحجام مرنة للصفحات على الحاسوب والهاتف.
- مؤثرات إطار Windows الأصلية عند دعمها؛ تبقى مساحة AMOLED أسود معتمًا، وتستخدم الألواح ألوانًا شفافة. لا يتطلب المظهر الزجاجي تغيير إعدادات النظام.
- خط Noto Sans Arabic مضمّن بترخيص SIL OFL 1.1؛ التفاصيل في `assets/fonts/`.
- حالة مستقلة لكل عملية، وتقدم وسرعة ووقت متبقٍ وإلغاء. قائمة انتظار بحد أقصى 50 عملية وأربع عمليات إرسال نشطة.
- إعادة محاولة الإرسال إلى المستلم الأصلي فقط؛ إعادة المحاولة تبدأ الملف من أوله.
- سجل محفوظ يتضمن النتيجة والجهاز واتجاه النقل، مع فتح الملفات أو نسخ النص الكامل. مسح السجل لا يحذف الملفات.
- إرسال الحافظة يدوي عبر «لصق» ثم «إرسال». نسخ النص المستلم تلقائيًا خيار منفصل ومعطل افتراضيًا.
- تصفح الملفات المستلمة وفتحها على Android دون اشتراط وجود مستلم متصل، مع إجراء لصق مستقل لرمز الاقتران وتوضيح فشل التحقق وإمكانية إعادة المحاولة.
- يحافظ إرسال النص على أي تعديل جديد في المسودة، وتظل عناصر القوائم مستقرة أثناء تحديث التقدم وحضور الأجهزة.

## النقل والاقتران

يستخدم البروتوكول 3 أسرار الاقتران المتبادلة لاشتقاق مفتاح مشترك، وتحديًا عشوائيًا لكل اتصال، وإطارات ChaCha20-Poly1305 موثقة مع ربط هوية المرسل والمستلم ومعرّف العملية وتسلسل الإطارات. تُشفّر النصوص وترويسات الملفات ومحتوى الملفات، ولا يوجد مسار رجوع إلى نقل بيانات المستخدم دون تشفير.

يُتحقق من SHA-256 لكل ملف مهما كان حجمه، وتُكتب الملفات المؤقتة بمعرّفات منفصلة. لا يُعلن الإرسال مكتملًا حتى يؤكد المستلم الحفظ والتحقق. توجد حدود لأحجام الرسائل والملفات والاتصالات، ومهل للشبكة، وإلغاء مستقل لكل عملية.

**تحديث الجهازين مطلوب:** البروتوكول الجديد غير متوافق مع 2.4.0. سجلات الثقة القديمة التي لا تحتوي على سر اقتران لا تمنح صلاحية استقبال. تبقى الملفات السابقة كما هي. على الحاسوب يُنقل السجل القديم من مجلد التنزيل السابق إن وجد إلى مجلد حالة التطبيق الخاص؛ على Android تبقى الملفات والسجلات القديمة في موقعها السابق.

الإصدار 2.4.2 متوافق مع 2.4.1، ولا يتطلب إعادة اقتران الأجهزة المقترنة بهذا الإصدار.

## Android

تُحفظ مفاتيح الاقتران والإعدادات داخل مجلد التطبيق الخاص، وتُستقبل الملفات داخل مجلد Flow القابل للكتابة دون اشتراط الوصول الشامل للتخزين.

متصفح الملفات مكتوب بـRust وSlint؛ لا يفتح منتقي نظام ثم يتجاهل نتيجته. الوصول إلى مجلدات الهاتف يتوقف على الأذونات وقيود إصدار Android. لا يستطيع Flow تجاوز قيود المجلدات المحمية.

في Android 10 وما بعده، إجراء **حفظ نسخة** في السجل ينشر نسخة من الملف في `Downloads/Flow` ثم يحاول فتحها بتطبيق مناسب. في Android 8 و9 يبقى الملف داخل مساحة Flow ويعرض التطبيق عدم دعم التصدير بهذه الطريقة. احفظ النسخ اللازمة قبل إزالة التطبيق.

قراءة وكتابة حافظة النصوص تستخدم JNI من Rust وتعرض الخطأ عند تعذر الوصول. لا توجد مراقبة خفية للحافظة في خلفية Android. نقل صور الحافظة كبروتوكول مستقل والاستئناف الجزئي القديم غير متاحين في البروتوكول الجديد؛ أرسل الصور كملفات.

## البناء والفحص

```powershell
cargo check --locked
cargo test --locked --lib --tests
cargo build --locked --release
```

تستخدم اختبارات الشبكة loopback ومنافذ مؤقتة. في بيئة تحظر الشبكة أو الكتابة إلى مجلد النظام المؤقت، يلزم السماح بـloopback وضبط `TEMP` و`TMP` إلى مجلد اختبار قابل للكتابة.

```powershell
# محاكاة الهاتف على الحاسوب؛ لها هوية وملفات منفصلة
cargo run -- --mobile

# نسخ اختبار معزولة دون لمس حالة المستخدم
cargo run -- --data-dir target/preview/one --downloads-dir target/preview/files --name "Flow Preview" --lang AR
```

### بناء Android

يتطلب Rust Android target وAndroid SDK/NDK وJDK وأداة `cargo-apk`.

```powershell
cargo check --locked --target aarch64-linux-android --lib
cargo apk build --lib --target aarch64-linux-android
```

لإصدار APK موقّع للإنتاج، اضبط `CARGO_APK_RELEASE_KEYSTORE` و`CARGO_APK_RELEASE_KEYSTORE_PASSWORD` في بيئة البناء، ثم شغّل `cargo apk build --release --lib --target aarch64-linux-android`. لم تعد بيانات التوقيع مكتوبة في المستودع. استخدم مفتاح الإصدار السابق نفسه إذا أردت تحديث التطبيق المثبت.

## حدود التحقق

الاختبارات الآلية تفحص التشفير والاقتران ورفض الرسائل غير المصرح بها والتلاعب وإعادة التشغيل والإلغاء والتزامن وسلامة الملفات والتخزين المحلي. اختبار Android على جهاز فعلي مطلوب لتأكيد تجربة الأذونات والحافظة وفتح الملفات حسب نوع الجهاز. لا تتضمن هذه الوثيقة أرقام استهلاك ذاكرة أو سرعات نقل غير مقاسة.
