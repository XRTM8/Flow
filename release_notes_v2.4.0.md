# FLOW by Otium v2.4.0 — The Unified Obsidian Hub Overhaul

Welcome to **FLOW by Otium v2.4.0**, a major design transformation in pure native Rust! This release completely eliminates unnecessary menus and tabs, unifying file beaming and live clipboard/text streaming into a single, high-fidelity Obsidian Glass command center.

---

### ✨ What's New in v2.4.0

#### 1. 🌌 Unified Obsidian Console (Zero Menus / Zero Fragmented Tabs)
- **Eliminated fragmented tabs**: No more jumping between STREAM, FILES, MESH, and ACTIVITY!
- Everything you need is immediately accessible on **one unified, breathing canvas**:
  - Direct Omnibar text & note composer.
  - One-click **"Send Files / Photos"** (emerald gradient).
  - One-click **"Beam Note"** (electric azure gradient).
  - Live received deck with instant copy and folder access.
  - Slide-over session activity history drawer.

#### 2. 🎨 Pixel-Perfect Vector Geometry (Lucide SVG Suite)
- Completely eliminated hand-drawn boxes and lines!
- Bundled full suite of high-resolution, vector SVG icons (`send`, `file-up`, `wifi`, `shield`, `folder`, `copy`, `check`, `history`, `monitor`, `smartphone`, `refresh`, `trash`, `x`) dynamically colored with Slint vector tinting.

#### 3. 💎 Pure Obsidian Glass Depth & Lighting
- Upgraded color system with `@linear-gradient` layered lighting:
  - Deep atmospheric obsidian background (`#0d111c` to `#06080e`).
  - Chamfered glass card surfaces catching subtle top light.
  - Smooth micro-interactions and hover animations (120ms ease-out).

#### 4. 📱 Android Keyboard & Screen Fixes
- Added `windowSoftInputMode="adjustResize"` to Android Manifest so the soft keyboard resizes the window naturally without covering inputs.
- Large, thumb-friendly touch targets (> 48px height) for effortless one-handed mobile use.
- Direct SAF file picker integration for full device storage and photo gallery access.
