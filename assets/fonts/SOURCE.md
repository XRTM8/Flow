# Noto Sans Arabic

Unmodified variable font from the official Google Fonts repository, renamed
from `NotoSansArabic[wdth,wght].ttf` to `NotoSansArabic.ttf` for a stable asset path.
Includes Arabic and Latin glyphs, weights 100–900, and width 62.5–100.

- Source: https://github.com/google/fonts/tree/main/ofl/notosansarabic
- Font metadata: https://github.com/google/fonts/blob/main/ofl/notosansarabic/METADATA.pb
